## Project Description

The primary goal of this project was to design and deploy an automated support system that not only answered generic questions but could also perform transactional tasks inside the company's internal software.

### Technical Solution

We deployed a serverless architecture based on **Cloudflare Workers** to ensure zero cost during downtime and instant scalability. The system processes incoming emails, constructs an intent map, queries the company database using semantic vector searches (RAG), and executes automated workflows such as:
- Simple invoice refunds.
- Password resets and account unlocking.
- Escalation of complex tickets to human representatives.
