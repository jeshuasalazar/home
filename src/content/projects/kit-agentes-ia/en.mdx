## The challenge

An accounting firm loses its mornings to the same work: answering WhatsApp, qualifying leads, following up on calls, reviewing supplier invoices and doing research. I wanted to show at a conference, live and with no tricks, how much of that AI agents can do.

## The solution

Five Claude Code agents, each with a clear role, read the same business documents (prices, policies, calendar) and work at the same time. A Python dashboard shows progress live, and a recorded run is the fallback if the venue's network fails. The invoice agent catches amounts that don't add up, mistyped tax IDs and duplicates before scheduling payments.

## Result

A morning of work in 39 seconds for US$0.87. I presented it at AMCP and published it so any business can install it with its own information.
