## Project Description

This project resolved invoice and billing inefficiencies for a global SaaS processing thousands of transactions monthly. The biggest challenge was synchronizing Stripe transactions with local accounting ledgers securely and instantly.

### Technical Solution

We built a lightweight and highly secure webhook gateway using **Cloudflare Workers**:
- Listens to Stripe events in real time.
- Validates the webhook payload integrity using **Zod** schemas.
- Automatically creates localized tax invoices and posts bookkeeping entries via REST APIs.
- Distributes customized tax receipts to clients via **Resend** using verified corporate SPF/DKIM domains.
