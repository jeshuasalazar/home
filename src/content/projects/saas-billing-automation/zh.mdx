## 项目描述

该项目解决了处理每月数千笔交易的全球 SaaS 的发票和计费效率低下问题。最大的挑战是安全、即时地将 Stripe 交易与本地会计账簿同步。

### 技术解决方案

我们使用 **Cloudflare Workers** 构建了一个轻量级且高度安全的 Webhook 网关：
- 实时监听 Stripe 事件。
- 使用 **Zod** 模式验证 Webhook 负载的完整性。
- 通过 REST API 自动创建符合当地税收的发票并过账记账条目。
- 使用经过验证的企业 SPF/DKIM 域名通过 **Resend** 向客户分发定制的税收收据。
